# Capstone Project

Create a portfolio-grade project that proves end-to-end ownership.

## Milestones

- [ ] Problem proposal and dataset vetting
- [ ] Reproducible baseline
- [ ] EDA, validation strategy, and error analysis
- [ ] Model comparison and justified selection
- [ ] Tested inference interface
- [ ] Containerization and deployment
- [ ] Monitoring or observability plan
- [ ] Architecture diagram and demo evidence
- [ ] Clear README and reproduction instructions
- [ ] Submission and required peer reviews

Keep project code under `src/`, tests under `tests/`, deployment configuration under `deploy/`, and small presentation assets under `reports/`.
