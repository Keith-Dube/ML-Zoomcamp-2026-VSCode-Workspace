# Midterm Project

Build one end-to-end ML system using Modules 1–6.

## Required shape

- [ ] Clear problem and measurable success criterion
- [ ] Public dataset with source and license
- [ ] EDA and leakage-safe validation
- [ ] Baseline plus at least two model candidates
- [ ] Final preprocessing and model pipeline
- [ ] Prediction API and Docker image
- [ ] Tests, reproducible setup, and useful README
- [ ] Deployment evidence
- [ ] Submission and required peer reviews

Place project-specific code under `src/`, tests under `tests/`, and screenshots or small reports under `reports/`.
